# IoT Smart Farm System

## Overview
An IoT-based smart agriculture monitoring system using ESP8266, MQTT, Flask, and sensors.

## Hardware
- ESP8266 NodeMCU
- DHT11 temperature/humidity sensor
- Soil moisture sensor
- LDR light sensor
- LCD I2C display

## Software
- MQTT (Mosquitto)
- Python Flask dashboard
- SQLite database

## Architecture

ESP8266 → MQTT Broker → Python Subscriber → Database → Flask Dashboard

## Features
- Real-time environmental monitoring
- Web dashboard visualization
- Sensor data storage
- Remote monitoring
